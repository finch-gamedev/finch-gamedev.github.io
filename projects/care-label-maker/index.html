洗標製作工具 Care Label Maker

在瀏覽器裡組合洗滌符號與文字，自動排版成標籤紙，直接列印或輸出 PDF。

日期
2026/05/26
標籤
#tool #web #react #typescript
網址
https://care-label-maker.finch-gamedev.workers.dev/

概述

給小品牌、手作者自己做衣物洗標的網頁工具。挑選洗滌符號、加上品牌與成分文字，設定標籤尺寸後，工具會自動排滿 A4、Letter 或捲筒標籤紙，直接列印或輸出 PDF。不用安裝、不用帳號，資料存在瀏覽器裡。

特色

  • 完整的 ISO 3758 符號：洗滌、漂白、乾燥、熨燙、專業清洗五大類共 61 個符號。
  • 預覽即成品：預覽、列印、PDF 共用同一份以 mm 為單位的 SVG，螢幕上看到的就是印出來的尺寸。
  • 自由組合內容：文字與符號區塊可任意堆疊、排序；符號放不下時標籤會自動增高，不會超出框線。
  • 中英雙語介面。

畫面

主畫面：左邊挑選洗滌符號，中間即時預覽排滿 A4 的標籤紙，右邊設定區塊內容與尺寸

預覽放大：符號以參數化生成，線寬一致；虛線為裁切框線

技術

本專案以 Claude Code 進行 AI 協作開發：我負責需求、功能規劃與驗收，程式碼主要由 AI 撰寫。

  • React + TypeScript + Vite，純前端，部署在 Cloudflare Workers
  • 符號以「基底形狀 + 修飾」參數化生成，線寬一致，也不依賴第三方美術素材
  • PDF 輸出使用 svg2pdf.js + jsPDF；狀態以 Zustand 管理並存在 localStorage

心得

這個工具的起點很單純：有朋友在蝦皮經營服飾賣場，每件衣服都需要洗標。市面上的做法不是找廠商訂製，就是自己用繪圖軟體一個個拼符號，數量少的小賣家兩種都不划算。所以我想做一個打開網頁就能用的工具，讓他們自己挑符號、排版、印出來。

因為是真的要拿去印的東西，我最在意的是「螢幕上看到的，就是印出來的樣子」。所以一開始就把預覽、列印、PDF 都建立在同一份 SVG 上，而不是做好之後再一個個去對齊尺寸。這個決定讓後面加功能時省了很多麻煩。
