交易工作台 chives

放在自己電腦上的台股交易筆記本與練習場：記錄多個券商帳戶的成交與損益，用歷史資料回測、驗證交易規則，再用紙上交易練習。

日期
2026/11/20
標籤

網址

概述

給想認真研究台股交易策略的個人使用的工作台。它不連券商、不幫你下單，也不推薦股票；它做的是把「記帳、研究、練習」放在同一個地方，而且所有資料只存在自己的電腦上。

上方連結是靜態展示版：畫面和程式與正式版相同，資料全部是合成的「示範市場」，不需要登入，也不會連到任何外部服務。

特色

  • 多帳戶帳務：記錄多個券商帳戶的成交、成本與已實現損益，並和券商對帳單逐筆核對。
  • 歷史資料：匯入多年、已還原除權息的台股日線；另外累積交易所官方的終止上市與除權息清單，用來檢查資料有沒有缺漏。
  • 策略研究：把一個交易規則拿去回測，再用「研究區間、驗證區間、保留測試」分段檢驗，加上參數敏感度比較，避免只是剛好在過去有效。
  • 紙上交易：用研究過的規則在之後的行情上模擬交易，看實際表現。
  • 給新手的引導：第一次使用先選目標，搭配逐步導覽、名詞小抄與學習中心。

畫面

以下截圖皆來自展示版，行情、價格與帳戶都是合成的測試資料。

帳務總覽：彙整各帳戶的已實現與未實現損益、持倉估值與交易費稅，下方列出每檔持倉明細

回測資產曲線：組合與等權買進持有、等權定期定額並列比較，下方為每日股票投入比例

分段研究：依序完成研究區間、驗證區間、凍結設定、一次保留測試，再寫下結論；每段的日期與資料涵蓋都列得清楚

技術

本專案以 Claude Code 進行 AI 協作開發：我負責需求、功能規劃與驗收，程式碼主要由 AI 撰寫。

  • 後端 Python + FastAPI + SQLAlchemy，資料存在本機 SQLite；前端 React + TypeScript + Vite
  • 用 Playwright 跑三十多組瀏覽器測試，每頁都檢查桌面與手機版面
  • 展示版是用真正的後端在合成市場上跑一遍，把每個回應錄下來，再組成不需要伺服器的靜態網站；發布前會自動掃描，確認裡面沒有任何真實帳戶、權杖或個人資料
  • 雙擊啟動，畫面上一鍵更新

心得

做這個工具的出發點，是想知道一個交易想法到底有沒有用，而不是憑感覺。過程中最花心思的是「不要騙自己」：回測很容易只是剛好擬合了過去，所以研究流程刻意把資料切成研究、驗證、保留測試三段，參數一旦凍結就不能再回頭調。

另一個重點是資料不出自己的電腦。帳務和研究結果都很私人，所以整個工具設計成在本機執行；要給別人看時，就用合成資料做出完全獨立的展示版。
