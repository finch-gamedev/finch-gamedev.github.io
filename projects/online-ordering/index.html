線上點餐系統

給小型餐飲店的線上點餐系統：顧客線上點餐、選擇取餐時間並付款，店家在後台接單、出單、管理菜單與庫存，全部建立在免費方案上。

日期
2026/05/27
標籤
#tool #web #nextjs #react #typescript
網址
https://online-ordering-plum.vercel.app/

概述

為小型餐飲店打造的到店取餐與內用點餐系統。顧客用手機打開網頁就能點餐、選擇取餐時間並付款；店家在後台接單、出單、管理菜單與庫存。資料庫與部署都使用免費方案，不需要月費，目前已有店家實際上線使用。

上方連結是展示版，可以直接試用顧客點餐的流程。

特色

  • 顧客點餐：依標籤瀏覽菜單，支援客製選項與加料；可選即時取餐或預約時段，時段只會顯示營業時間內的選項。
  • 多種付款方式：現金、LINE Pay、ECPay 信用卡。
  • 內用桌號點餐：每桌產生專屬 QR Code，顧客掃描後自動帶入桌號。
  • 店家後台：訂單接單與狀態管理、幫客人點餐、庫存自動扣減、菜單編輯與 CSV 匯入匯出、營業報表。
  • 出單與通知：支援藍牙、USB、WiFi 與序列埠出單機；新訂單可透過 LINE、Discord、Telegram 或 email 通知店家。
  • 顧客集點、中英雙語介面，以及可在後台調整的主題與深色模式。

畫面

以下截圖皆為展示版的測試資料。

顧客端

顧客端菜單：依標籤篩選品項，售完的品項會自動停用

手機上的客製選項：麵體、口味單選，加料可調數量，售完選項自動停用

店家後台

後台儀表板：待接單、今日與全部訂單數，以及各功能入口

訂單管理：依狀態篩選，每張訂單顯示品項、加料、付款方式與取餐時間

營業報表：可選日期區間，統計收款、訂單狀態、熱銷品項與付款方式

外觀主題：選擇配色或自訂顏色，並即時預覽前台效果

技術

本專案以 Claude Code 進行 AI 協作開發：我負責需求、功能規劃與驗收，程式碼主要由 AI 撰寫。

  • Next.js（App Router）+ React + TypeScript + Tailwind CSS，部署在 Vercel
  • 資料庫可在 Google Sheets 與 Supabase（PostgreSQL）之間切換，兩者共用同一份資料結構定義，欄位變更時自動遷移
  • 金流串接 LINE Pay 與 ECPay；圖片上傳使用 Cloudinary

心得

這個系統是幫朋友的店做的。當時的需求很明確：想要有自己的線上點餐，但不想負擔每個月的系統費用。所以從第一版開始，就把「全部用免費方案」當成前提：資料直接存在 Google Sheets，店家打開試算表就能看到訂單；網站部署在 Vercel 的免費方案上。

隨著功能越加越多，也預留了往上擴充的路：資料層抽象成同一份結構定義，資料量變大時可以改用 Supabase，而不必重寫整個系統。
